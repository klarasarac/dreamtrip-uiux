# DreamTrip – UI/UX Design Project

## Overview
DreamTrip is a modern travel landing page designed in Figma.  
The goal of this project was to create a clean, visually appealing and user-friendly interface for a trip planning platform.

This project focuses on layout structure, visual hierarchy and clear call-to-action sections.

---

## My Role
UI/UX Designer

---

## Tools Used
- Figma
- Auto Layout
- Components
- Prototyping

---

## Design Goals
- Create a strong and engaging hero section
- Design clean and consistent destination cards
- Structure content clearly (Explore → Plan → Enjoy)
- Maintain visual balance and spacing
- Use natural color tones suitable for a travel brand

---

## UX Considerations
- Clear navigation structure
- Strong CTA buttons for user guidance
- Logical section flow
- Responsive layout concept
